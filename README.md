# AI & Python Quiz Challenge

## 프로젝트 개요
Python 콘솔에서 실행하는 4지선다형 퀴즈 게임입니다. 문제 추가, 목록 조회, 퀴즈 풀기, 점수 확인을 지원합니다.

## 퀴즈 주제 선정 이유
Python, API, Git, AI의 핵심 개념을 퀴즈로 복습하면서 파일 입출력과 객체지향 프로그래밍을 연습하기 위해 선정했습니다.

## 실행 방법
Python 3.9 이상을 설치하고 프로젝트 폴더에서 다음 명령어를 실행합니다.

```bash
python main.py
```

Windows에서 `python` 명령이 작동하지 않으면 `py main.py`를 사용합니다.

## 메뉴 출력 예시
프로그램을 실행하면 다음 메뉴가 표시됩니다.

```text
=== AI & Python Quiz Challenge ===
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
메뉴 번호 선택:
```

## 기능 목록
- 1: 퀴즈 풀기 — 문제 중 최대 5개를 무작위로 출제하고 100점 만점으로 채점
- 2: 퀴즈 추가 — 문제, 보기 4개, 정답 번호 입력 및 저장
- 3: 퀴즈 목록 — 저장된 문제 전체 조회
- 4: 점수 확인 — 최근 점수 및 최고 점수 표시
- 5: 종료 — 저장 후 종료

## 입력 중단 및 예외 처리
- 실행 중 `Ctrl+C`를 누르면 중단 안내를 표시하고 현재 저장된 게임 상태를 저장한 뒤 종료합니다.
- 입력 스트림이 끝나면(`EOFError`) 종료 안내를 표시하고 게임 상태를 저장합니다. Windows에서는 `Ctrl+Z` 후 `Enter`, macOS/Linux에서는 `Ctrl+D`로 입력을 종료할 수 있습니다.
- 중단 시 진행 중인 퀴즈 답변이나 완료되지 않은 퀴즈 등록은 저장되지 않습니다.

## 파일 구조
```text
ai-python-quiz/
├── main.py
├── state.json      # 첫 실행 시 자동 생성
├── README.md
└── .gitignore
```

## 데이터 파일 저장 및 동기화
`state.json`은 프로젝트 루트의 UTF-8 파일입니다. `quizzes`에 문제/보기/정답을, `last_score`와 `high_score`에 최근 및 최고 점수를 저장하며, 실행 시 자동으로 불러옵니다. 파일이 없으면 기본 퀴즈와 점수로 새 파일을 만듭니다.

다음 시점에 현재 상태를 저장합니다.
- 퀴즈 등록이 완료된 직후
- 퀴즈 한 판이 끝나 점수가 계산된 직후
- 메뉴에서 `5. 종료`를 선택하거나 입력 종료(`EOFError`) 또는 `Ctrl+C`로 프로그램을 중단할 때

저장할 때 기존 `state.json` 내용을 직접 덮어씁니다. 자동 백업은 만들지 않으므로 중요한 진행 상태는 저장 전에 파일을 별도로 복사해 두세요. 파일을 읽을 수 없어 기본 퀴즈로 시작한 경우에도 다음 저장 때 기존 파일이 기본 데이터로 덮어써질 수 있습니다.

`state.json`은 Git 추적 대상입니다. 커밋하고 푸시하면 저장된 문제와 점수도 원격 저장소에 공유되며, 다른 버전을 가져오면 로컬 파일이 바뀌거나 충돌할 수 있습니다. 로컬 진행 상태를 보존하려면 동기화 전에 별도 백업을 만들어 두세요.

## 클래스 구성
- `Quiz`: 퀴즈 데이터 및 문제 출제
- `QuizGame`: 메뉴, 게임 진행, 퀴즈 추가/조회, 점수 관리, JSON 저장/불러오기
